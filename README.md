# Linux for DevOps

A hands-on Linux learning guide based on *The Linux Command Line* by William Shotts.

## Goal

Build practical Linux command-line skills from the ground up and apply them to DevOps.

## Learning Method

- Learn one concept at a time
- Practice it on WSL
- Debug mistakes
- Complete microtasks
- Review with interview questions
- Commit progress to Git

## Curriculum

The learning sequence follows the reference curriculum chapter by chapter.

### Part I — Learning the Shell

1. What Is the Shell?
2. Navigation
3. Exploring the System
4. Manipulating Files and Directories
5. Working with Commands
6. Redirection
7. Seeing the World as the Shell Sees It
8. Advanced Keyboard Tricks
9. Permissions
10. Processes
